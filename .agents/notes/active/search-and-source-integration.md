# 搜索、发现与真实来源适配

## 2026-10-26 已批准的新要求与实施

- 安卓“网游之”搜索失败已定位为旧网页 HTML 搜索适配失效。采用官网新 /api/search/result JSON 入口，无须把本机注册身份打包给其他安装；已有本机访客配置时原 App 适配仍可使用。
- 每次主动搜索、刷新都实时请求；失败清空旧列表和分页结果，后续相同关键词必须再次联网。官网新分页只保留 ID 用于跨页去重，不作为结果缓存；已有本机配置的 App 游标适配保留其后退页缓存，但主动提交仍开启新会话。历史网页只能首批的结论不再适用于新官网入口。
- 播放页底部相关推荐：官网同页 related_list + 基于标题的下一季 / 番外检索；支持中文数字和阿拉伯数字，按 ID 去重并优先展示手工检索结果。名称推断标为“同名系列”，不冒充官方同系列认证。
- 当前剧最后一集播放到 80% 时，再刷新一次相关检索；切剧、关闭页面后的旧响应不得更新新页面。App 专用关联端点尚未验证，不按猜测构造请求。
- 接口与实测边界见 .agents/api/website.md。相关功能在用户验收前保持 active。

## 必须满足的行为

- 默认搜索使用可用的来源搜索入口，首批返回即可展示，保留来源顺序。不得在默认搜索前或后台悄悄扫描整个分类片库。
- 缺失热度可后台补充，不能阻塞首批结果；统计失败不能隐藏剧集。热度、播放次数、评分、收藏数必须区分，缺失数据不能编造。
- 真实搜索分页应使用服务端给出的游标、偏移和会话条件。验收至少覆盖同一关键词连续取得两个不同结果批次、排除重复页、返回上页以及请求失败后的可解释状态。
- 原生搜索后页未接通时，必须明确说明边界。网页首批的来源报告总数不能当作当前已可浏览的完整结果数量。
- 分类片库补充检索只能由用户主动触发，明确告知较慢与检索范围；可对补充结果本地分页，但不能冒充原生全站搜索分页。
- 真实榜单保留来源排名，支持后页；漫剧分类支持后页。随机推荐需明确为从分类抽取，不冒充个性化推荐。
- 关联作品按同名或真实元数据推断时必须标记依据，不擅自合并同名不同 ID 的剧集。
- 发起取流前重新加载完整分集和实际可用画质。

## 来源事实与验收边界

- 网页搜索在既有验证中返回首批约 10 条，增加 `page=2` / `offset` 等参数仍重复首批；这只说明已测试入口的行为，不能推断网站永远没有后页能力。
- 已测试 App 搜索 `/reading/bookapi/search/tab/v` 及带尾斜杠形式，多种 tab / 网关得到 HTTP 200 空响应。不得据此宣称官方 App 本身只能搜索一页。
- MiniReel 搜索的底部观察尚不足以证明其接口路径或限制；没有取得请求就不能断言与网页属于同一原因。
- 正常官方 App 操作与流量观测应优先用于确认实际端点、请求参数、响应结构和连续加载条件；不能把公网参考实现中的游标字段当成已经实测的字段。
- 真实取流使用完整签名的 `POST /novel/player/multi_video_model/v1/`、`mixed_video_id_map` 与正确的媒体解析链路。详情或取流能用，不能推断搜索必然能用。

## 抓包和数据边界

- 使用用户授权的本地模拟器 / 设备；抓取范围限定到红果 `com.phoenix.read`，避免其他应用流量。
- 优先选择无需付费即可完成所需操作的开源工具。PCAPdroid 与开源 mitm 组件、mitmproxy 是已选择的路线，不要求用户购买 Reqable。
- 证书安装成功、代理连通、TLS 连接出现，都不等于已经读到 HTTPS 明文；必须用实际 URL、请求 / 响应或可解码记录验证。
- 用户认证、锁屏密码、登录验证码交由用户操作，不接收或保存密码，不绕过锁屏。
- 不把抓包中的 Cookie、令牌、设备身份、签名、证书私钥写进产品或公开文档。原始记录保留在被 Git 忽略的诊断目录，只输出必要的脱敏事实。
- 未证明原因前，不把 TLS 失败一概称作证书绑定；不得擅自对官方 App 重签、关闭校验或更改宿主机安全设置。
