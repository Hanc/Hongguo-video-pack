# 0.2.1 验收说明

日期：2026-10-16。本版交付 Windows x64 安装程序、Android 8.0+ ARM64 APK 与对应源码。

## 本轮修改

- 删除截图红框中的标题栏 HONGGUO / STUDIO、侧栏 MAKE STORIES FLOW、搜索框示例文字。保留窗口拖动区域和最小化 / 最大化 / 关闭按钮。
- 默认搜索直接请求红果网页，来源返回即展示，保持来源顺序；不扫描分类片库、不等待额外详情请求。实测一次请求返回 10 条，首批耗时约 0.3–1.6 秒，具体依网络而异。
- 网页结果已有热度直接展示；缺失热度在后台最多 3 个并行请求补充，失败不会隐藏搜索结果。旧查询的统计响应不能覆盖新查询。
- 网页 page=2 仍重复首批；App 搜索 /tab/v 与 /tab/v/、多个 tab 和两台官方网关复测仍为 HTTP 200 空响应。因此没有声称实现原生全站搜索后页。
- 用户主动点击“补充检索分类片库（较慢）”才建立分类索引，补充结果保留每页 20 条、上下页和 30 分钟缓存。默认搜索禁止自动或后台扫描整个片库。
- Windows 改为 Inno Setup 安装程序：可选择目录、开始菜单启动 / 卸载入口、可选桌面快捷方式，注册到系统应用列表。当前用户安装，无需管理员权限。卸载保留用户设置和导出视频；安装不会强制关闭正在运行的任务。

## 验证

- 29 项 Flutter 自动化测试通过，包括真实联网搜索、补充结果分页、默认搜索仅一次请求且不扫描片库、搜索不等待热度、旧响应隔离、原取流协议、媒体兼容和窄屏界面。
- 1320 / 390 / 320 宽度下检查红框文字删除与导航、详情弹层交互；截图为渲染测试数据。
- Windows Release 和 Android Release 构建；APK 签名与版本检查。
- 安装包安装、开始菜单快捷方式、卸载注册、内置引擎启动及卸载后保留用户文件，使用 scripts/test-installer.ps1 在隔离目录验证。
- 同规格拼接和差异修复的验证基线见 acceptance-0.2.0.md。

## 验收步骤

1. 先等待旧版任务结束，退出旧版；运行 Hongguo-Studio-Windows-0.2.1-Setup.exe 安装。
2. 从开始菜单打开红果工坊，确认三处红框文字已移除。
3. 搜索剧名，先展示网页首批和来源热度，不应出现建索引等待。界面标注网页返回条数与来源报告总数，不把首批冒充完整结果。
4. 如需更多结果，主动点击补充检索；该操作会扫描分类片库，结果可翻页，范围不是全站。
5. 正常选剧、选集、导出，验证已有完整分集缓存可以复用；从任务页打开视频。
6. 系统应用列表或开始菜单可以卸载，导出文件与用户配置保留。

## 边界

当前仅有 Windows / Android 构建，Linux 和 macOS 安装包未交付。安卓没有连接真机，安装与系统保存仍待设备验收。原生 App 搜索后页仍未打通；本次修复的是默认搜索速度、明确可选补充检索和安装交付。
