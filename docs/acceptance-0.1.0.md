# 0.1.0 验收说明

日期：2026-10-16。交付目标：Windows x64 便携版、Android 8.0+ ARM64 APK，以及对应应用源码。

## 已实现

- 单剧链接 / 数字 ID 导入，剧集详情与完整分集展示。
- 点选、全选、范围选择；恢复上次任务的分集与清晰度选择。
- 通过批量视频模型接口及完整签名获取来源实际返回的兼容画质；未接入第三方解析服务器或 MiniReel 进程。
- 选择清晰度，按集顺序下载，失败最多重试三次；已完成分集校验后复用。
- 优先无损拼接。可选自动兼容：当编码、分辨率、帧率或音轨参数不一致时转码统一；关闭后明确提示，不偷偷改画质。
- 导入本地视频、调整顺序、拼接输出；取消任务；下载时长与轨道校验。
- 导出记录持久化；打开导出文件；清理分集缓存时保留成品。
- Windows 无需另装 Flutter、Node、FFmpeg 或 C++ 运行库。Android 使用原生签名、前台服务和系统文件保存，不依赖桌面程序。
- Borderless 布局：无卡片边框，使用 shadow + gap；桌面和窄屏布局。

## 验收步骤

1. Windows 解压整个便携包，运行 `hongguo_studio.exe`。
2. 保留默认示例链接，点击“读取剧集”。应显示《持械入宋：第一季》100 集和当前兼容清晰度。
3. 首次先选 1–2 集，点击“下载并拼接”。任务结束后用支持 HEVC 的播放器打开导出视频，应有视频和声音，时长约 4 分钟。
4. 再次执行同一选择，任务动态应显示复用已下载分集。
5. 尝试选择范围、取消任务、重新执行以及清理缓存；成品 MP4 不应被清理。
6. 安卓安装 APK 后执行相同流程。导出完成后点“保存到手机”，选择系统目录，再用手机播放器打开保存的视频。

## 本版边界与待真机确认

- 本版采用访客来源；当前示例已可返回 1080P，**没有实现红果官方账号登录**。不伪造登录状态，也不保证来源未返回的画质。
- 低档资源如果使用当前引擎不支持的 ByteVC2，不会出现在可下载清晰度里；例如本次示例实际可处理档位为 1080P。
- 若某集缺少所选画质，会明确提示调整或重试，不把其他集或低清预览冒充该集。
- 未覆盖榜单、搜索、关联漫剧或随机推荐；这些属于后续版本。
- 已完成分集可复用，但单集未完成部分会重新下载，非字节级断点续传。
- 当前环境未连接安卓真机，且不能启用硬件加速模拟器。**安卓安装、系统文件选择/保存、通知及厂商后台策略尚未做设备级验收。** Native 签名联网验证是在 JVM 测试环境运行，不能冒称真机测试。
- 未进行 100 集整剧下载压力测试；本次真实端到端测试为前两集。长批次需要足够磁盘空间；兼容转码耗时取决于设备。

交付包为可本地验收的首版，不是商店上架版本。Android 使用工作区独立发布密钥；Windows 未做商业代码签名。源码和第三方声明随包提供，校验和见 `dist/SHA256SUMS.txt`。
