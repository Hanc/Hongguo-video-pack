# 0.2.0 验收说明

日期：2026-10-16。Windows x64 便携版、Android 8.0+ ARM64 APK、对应源码包。

## 本轮功能

- 发现页：官方总热播榜、真人剧榜、漫剧榜、AI 剧榜，支持加载后页。
- 漫剧剧库：真实分类分页，点击卡片查看简介并加入工作台，重新读取完整分集。
- 搜索：每页 20 部，上一页 / 下一页，重复页检测与去重；失败可以重试，旧请求不会覆盖新查询。
- 搜索热度：从来源搜索 / 详情页读取热度；有明确播放次数才显示播放量，缺失则省略，不以评分冒充播放量。每页补充统计最多 3 个并行请求。
- 关联作品：去除季数后检索同名系列，排除当前剧集；界面说明关联依据，不冒充官方关联。
- 随机推荐：按真人剧、漫剧、AI 剧随机选页抽取，本次会话尽量去重，支持换一批。
- 桌面侧栏和移动端底部导航分为发现、工作台、任务。任务进行中可以浏览，禁止切换导出中的剧集。
- 纯尺寸差异取出现最多的规格，优先只缩放 / 补黑差异集数，保留相同规格原流。混合编码结果需完整音视频解码校验；不兼容时才回退全量统一转码。
- 编码、解码最多 2 线程，滤镜 1 线程；HEVC 编码另限制线程池。逐集处理。**这不是 Windows Job Object CPU 硬配额，不能保证固定占用百分比。**

## 搜索范围

官网搜索页传 page=2 仍返回首批，App 搜索接口本轮测试返回 HTTP 200 空响应。因此本版扫描可正常分页的官网真人剧、漫剧、AI 剧分类并建立本地标题索引，补充官网搜索首批；每类当前约 800 部，结果按实际匹配数分页，不能声称覆盖全站。

首次建索引有等待提示与已读取数量；完成后应用支持目录保存 catalogue-v1.json，30 分钟内复用。热度仅补充当前页，不为整库批量请求详情。

## 验证证据

- Flutter 静态检查无问题。
- 27 项自动化测试全部通过（含真实来源联网验证），覆盖分页不重复、重复上游页报错、过期响应隔离、热度与播放量区分、线程预算、最常见规格选择、HEVC 差异修复和完整解码。
- 实际联网：榜单第 1、2 页排名前进；漫剧分类第 1、2 页 ID 不重复。关键词“我”本次匹配 734 部，两页各 20 部且 ID 无交集；第二页热度补充成功。
- 《持械入宋》排除当前第一季后检索出其他季。结果包含同名不同 ID 的版本，不擅自合并为同一部。
- Windows 内置 FFmpeg 实际运行：生成 3 个不同高度的 HEVC 素材，保留 2 个原流、仅处理 1 个差异片段，拼接后完整解码成功，未回退全量转码。
- 1320 / 390 / 320 宽度的发现页、详情弹层、导航与原工作台分集交互测试；渲染截图为自动化测试数据，非安卓真机截图。
- 0.2.0 Windows Release 端到端：读取《持械入宋：第一季》100 集及 1080P，复用前两集缓存并拼接，输出 HEVC 1080×1920 + AAC、240.953447 秒，完整音视频解码通过。
- 原有真实取流、缓存、导出基线见 acceptance-0.1.0.md；媒体密钥、签名地址和下载视频均不打包。

## 验收步骤

1. 解压 0.2.0 Windows 便携包，启动 exe；保留 data、runtime 与 DLL。
2. 在发现页切换榜单、加载后页，进入漫剧库并加载更多；点击卡片查看详情。
3. 搜索“我”，等待首次索引完成，翻到下一页；应展示不同剧集与可取得的热度，上一页可返回。
4. 搜索“持械入宋”，选择第一季加入工作台；确认完整分集与实际画质，查看“关联作品 / 其他季”。
5. 随机推荐选择分类并换一批，点击喜欢的剧集加入工作台。
6. 先下载 1–2 集验证成品；任务页查看状态、取消或打开导出。已有完整分集缓存可复用。
7. 安卓安装升级 APK，检查底部导航、搜索翻页、分集选择、导出与“保存到手机”。

## 交付边界

- 仍为访客来源，未实现官方账号登录，只展示来源实际返回的兼容画质。
- Windows Release 和 Android Release 构建成功；APK 签名验证通过，versionCode=2、versionName=0.2.0、minSdk=26，仅包含 arm64-v8a。
- 安卓已构建；本环境没有连接安卓设备，安装、系统保存、热管理和厂商后台行为仍需真机验收。

- 不覆盖正在运行的 0.1.0 程序，不自动取消旧任务；新版本需另外启动。
