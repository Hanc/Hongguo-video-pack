# 红葡萄 0.4.1：正式版更新与 Gitee 镜像

- 包含 0.4.0 的观看记录能力，新增启动自动检查、“关于 → 检查更新”、下载进度/取消与系统安装入口。
- 只比较纯三段正式版号，忽略预发布和版本后缀；国内镜像优先，GitHub 备用，安装包 SHA256 校验后再运行。
- 旧版 0.3.0 没有内置更新功能，需要先手动安装带此功能的版本。以后随正式 Tag 发布即可在应用内发现更新。
- Android 更新仍需系统安装确认；第一次可能需要在系统设置允许本应用安装。正在拼接时会阻止安装。
- Gitee 代码与正式 Release 的自动同步配置见 `docs/releasing.md`。
- 本轮不创建新版本 Tag，不改变 v0.3.0 的发布内容。手机上的系统授权和覆盖安装仍需设备验证。

## 已验证

- 全量 65 项测试通过、4 项跳过；覆盖正式版筛选、数值比较、分页、国内源优先/故障回退、SHA256/BOM 校验、下载取消、安装前篡改检测、拼接任务阻止安装，以及 320/1320 更新页布局。
- Windows 实际成品读取安装版本 `0.4.1` 并查询公开版本接口，识别正式版 `0.3.0`、`hasUpdate=false`，未触发降级。
- Windows Release 与 Android arm64 发布签名构建完成；Android 系统安装确认需手机验收。
