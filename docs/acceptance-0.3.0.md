# 红葡萄 0.3.0 验收

2026-10-19（Asia/Shanghai）。本版包含品牌更名和双端内置播放，不增加账号登录，不将本机访客身份打入分发包。

## 变更

- 选用提供的方形 `logo1.png`，裁去外围空白后生成侧栏、Windows ICO 和 Android 各密度启动图标，保留原图案。
- 已将红底圆角外背景改为真正透明；每个 ICO 尺寸验证四角 Alpha=0，保留内部不透明白色葡萄，见 `docs/branding.md`。
- 窗口、安装器、快捷方式、About、Android 应用标签和导出通知更名为“红葡萄”。内部包标识、签名和升级 AppId 保留。
- 更名引起 Windows 产品支持目录变化时，只迁移已知设置/访客配置/分类缓存，不覆盖新配置，不移动成品视频。
- 搜索/榜单卡片直接播放，另有拼接按钮；长按可看简介。
- 播放页支持切集、进度拖动、实际清晰度、自动连播和拼接范围选择；右上角进入同一拼接任务的管理面板，查看、取消或打开导出。
- 播放与导出状态隔离。任务正在进行时可继续播放，不覆盖当前任务；关闭播放页停止播放器，导出继续。

## 已验证与边界

- Flutter 回归：42 项通过、4 项跳过；包括旧响应隔离、清晰度恢复位置、连播开关、拼接选择隔离、桌面/390/320 宽度下的播放与任务入口。
- Windows 内置播放器实际读取两集 1080P HEVC/CENC 视频，分别取得 1080×1920 解码画面，验证下一集更换密钥和进度拖动。报告为 `.local/playback-acceptance/result.json`。
- 实测播放期间可同时运行内置拼接/尺寸修复引擎检查，两套原生媒体库共存；不把此小样本视为完整长剧资源占用验收。
- 更名后的 Windows 成品仍通过两页搜索与 14 张封面实际解码，并验证旧访客配置迁移。
- 新增依赖没有引入 `jni` 包；已检查播放器 DLL 的直接 PE 依赖，无 JVM 项。安装包继续包含原生媒体库、CRT 和签名 Node 运行时。
- Android 完成发布构建；真实手机的音画、硬件解码、全屏/旋转、系统保存与后台长任务需用户验收，不以 Windows 或模拟器环境代替。
- 首次自动访客注册仍未完成：本机已配置的搜索可以分页，未配置的新设备仍是明确标注的网页首批；播放和取流不要求账号登录。

## 下一轮建议顺序

1. 退出旧版本，Windows 使用新安装包升级；Android 使用同包名正式签名 APK 升级安装。
2. 检查桌面/启动器图标和名称；确认原导出记录与设置仍在。
3. 在榜单或搜索点击“播放”，确认首帧、声音、暂停、拖动、切集及清晰度切换。
4. 播放页切“选择拼接”，选少量分集，点击“拼接所选”；打开任务管理检查进度、取消或完成后的成品。
5. 拼接过程中继续播放、返回列表再进入播放，确认任务不被覆盖；完成后查看成品音画。

本版没有以小样本验收替代完整长剧与真实 Android 热管理测试。源码包和 API 文档随交付保留；`.local`、访客配置、原始抓包、签名材料不分发。

## 安卓验收追加：单行分类与全屏手势

- 榜单四个分类保持单行，手机使用 12 号字体和紧凑间距；空间不足或系统放大字体时横向滚动，不强制换行。390 / 320 宽度回归与真实字体截图已检查。
- 手机横屏全屏播放时，左侧三分之一上下拖动调窗口亮度，右侧三分之一调系统媒体音量，中间三分之一上滑下一集、下滑上一集。切集需要至少 64 逻辑像素，并在松手时执行一次。
- 横拖预览进度，松手跳转；限定到当前视频时长内，取消手势不跳转。首次超过 16 逻辑像素后锁定方向，顶部控制区与底部进度条保留原有操作。
- 亮度仅调整当前窗口，退出全屏恢复进入前的亮度；音量使用系统媒体流。两者都有百分比提示，切集与横拖也提供反馈。
- Flutter analyze 无问题；43 项测试通过、4 项跳过。新增手势测试覆盖分区、进度上下界、取消和退出清理。真实 Android 的音量、亮度、全屏旋转和连续切集仍待手机验收。
- 此追加不打 Tag、不发布 Release；安卓验收通过后再发布。
