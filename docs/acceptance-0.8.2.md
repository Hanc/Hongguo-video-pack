# 红葡萄 0.8.0–0.8.2 验收

2026-10-23（Asia/Shanghai）。本版聚焦播放页交互与搜索可用性，不新增账号、不改变交付结构。

## 变更

- 0.8.0 长按加速：长按 400 ms 升到 2 倍（不再往上叠加），松手恢复原速；暂停状态下长按同时恢复播放。
- 0.8.1 手势改为红果式：**整屏**上下滑切下一集 / 上一集（不再限制在中三分之一，阈值 48 逻辑像素）；左右两侧双击前后跳 10 秒、中间双击暂停；亮度与音量手势取消，改由系统控制。控制栏改为自绘，保留倍速、可拖进度条、全屏与退出全屏，并且不再使用 `media_kit` 的内置控制层——它在 `onPointerDown` 里就切换遮罩，长按加速必然把下方控制栏顶出来。
- 0.8.2 修复首页搜索：来源网站的 `/search/<关键词>` 已改为前端渲染，HTTP 200 但只有约 37 KB 脚本外壳、没有 `window._ROUTER_DATA`，旧解析统一抛 `FormatException('剧库页面缺少数据')`。搜索改走首页脚本同样调用的 `GET /api/search/result?query=&page=`，恢复结果并支持真实翻页（此前只有网页首批，且「补充检索」是唯一补救路径）。

## 已验证

- `dart analyze`：No issues found。
- `flutter test`：66 项通过、4 项跳过。新增/改写：搜索走 API 单次请求且不再扫片库；API 第 2 页游标与超出页报错；封面对齐测试改用 JSON 形状。
- `--switch-acceptance`（本地样片，不依赖网络）：倍速 1.5 生效并在切集后保持，切集后暂停位置未被清掉，画面在个位数毫秒内出帧。
- `--search-acceptance`（真实来源，Windows 成品）：`{"passed":true,"path":"website","first":10,"second":10,"freshOnSecond":9,"overlap":1,"repeatStable":true,"pages":22,"total":213,"more":true,"heat":10,"coversDecoded":20}`。即两页各 10 条、后页带来 9 条新剧、`totalPages` 22 与 `hasMore` 一致、热度全部解析、20 张封面实际下载并解码。

## 边界与已知上游行为

- 上游分页会稳定重复 1 条边界条目（实测 `page=1` 第 6 条即 `page=2` 第 1 条），所以翻页时相邻两页可能看到同一部剧一次；这是来源行为，程序不篡改条目，验收按「至多 1 条重叠、后页至少 9 条新剧」判定。
- 单页请求曾出现 502。失败时程序报错可重试，不把一次失败当成「该关键词无结果」。
- 搜索框的界面点选未在本轮做交互式验收（构建环境无可点击的 GUI）：GUI 与验收共用 `DiscoveryController.search` → `DiscoveryClient.search` 同一条路径，界面部分由既有 widget 测试与上述真实来源验收间接覆盖。
- Android 端手势、长按加速与全屏行为仍需真机验收，不以 Windows 结果替代。

## 下一轮建议顺序

1. 用 `Hongputao-Windows-0.8.2-Setup.exe` 覆盖安装（无需关闭旧任务；安装前建议退出旧版）。
2. 首页搜索排行里的剧名，确认能出结果、能翻到第 2 页。
3. 全屏后上下滑切集、左右双击跳 10 秒、长按加速，确认长按期间不再弹出控制栏。
4. Android 用同包名签名 APK 覆盖安装，重复第 2、3 步。
