# 0.3.2 预览验证（2026-10-26）

当前为未打 Tag 的预览实现，线上 0.3.1 Release 保留。版本 0.3.2+11。

## 实现

- 修复安卓无 App 搜索初始化配置时旧网页搜索失效，接入 /api/search/result。重新搜索和刷新实时联网，失败清空旧结果；官网前后页重新请求，仅按当前搜索各页 ID 去重。已有本机身份的 App 搜索仍保留其独立游标适配。
- 当前集达到 80% 后准备下一集；播放页开关持久化。完整缓存实际媒体字节，限制 64 MiB，失败不打断当前播放。切集使用缓存并保留对应 CENC 参数，缓存文件在播放器停止使用后删除；禁用、切剧、后台、退出取消待加载。
- 播放页底部展示来源相关推荐与下一季 / 番外检索，支持中文数字、阿拉伯数字；手工检索优先，按剧集 ID 去重。只把下一季及同前缀番外列为手工匹配，排除当前 ID；最后一集达到 80% 时刷新一次。来源推荐当前为官网 detail 的 related_list，不是尚未验证的 App 专用关联 API，不混入 hot_list。
- App 详情空响应时先回退官网详情的完整 vid_list，再保留原播放页回退；校验 ID 及分集总数，拒绝将预览列表当完整分集。

- 新增回归覆盖：搜索失败清空及同词重试、错误页码、80% 单次预加载、禁用及失败不打断、文件完整性 / 大小上限、取消清理、设置持久化、中文数字、下一季与番外、优先级与去重、来源推荐与热门隔离、320 / 390 宽度操作及相关剧集显示、详情完整分集校验。
